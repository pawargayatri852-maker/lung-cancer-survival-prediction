# Lung Cancer Survival Prediction Using Machine Learning

## Project Overview
This project predicts lung cancer survival outcomes using machine learning classification algorithms in Python.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Scikit-learn
- Matplotlib

## Machine Learning Algorithms
1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Support Vector Machine (SVM)
4. Decision Tree
5. Random Forest
6. Gaussian Naive Bayes
7. AdaBoost
8. Gradient Boosting

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix
- 5-Fold Stratified Cross-Validation

## Best Model
AdaBoost achieved a mean cross-validation accuracy of 72.40% in the reported experiment.

## Disclaimer
This project is for educational purposes only and is not intended for clinical diagnosis or medical decision-making.
